# 🌀 ESP32 智慧散熱監控系統

這是一個基於 ESP32 開發的自動化散熱解決方案，整合了物聯網（IoT）技術，支援實時溫濕度監測、自動化硬體回饋以及遠端網頁控制。

## 🛠️ 硬體材料

* **核心控制器**: ESP32 DevKit V4
* **感測模組**: DHT22 / DHT11 溫溼度感測器
* **顯示模組**: I2C 1602 LCD 螢幕
* **狀態指示燈**:
  * 🔴 紅色 LED：代表溫度過高
  * 🟢 綠色 LED：代表運作正常
* **動力元件**: USB風扇 (模擬器中使用藍色LED替代)

## 💻 核心技術

* **開發環境**:
  * Arduino IDE 實體燒錄
  * Woki 線上模擬器
* **通訊協議**: Wi-Fi (HTTP Webserver)
* **使用函式庫**:
  * <WiFi.h>
  * <WebServer.h>
  * <DHT.h>
  * <LiquidCrystal_I2C.h>

## 主要功能

* **實時環境偵測**：系統啟動後，即時偵測環境溫溼度變化，並顯示於 LCD 螢幕上。
* **智慧溫控邏輯**：
  * 溫度於正常值內亮**綠燈**。
  * 溫度超過設定值（如 45°C）亮**紅燈**並啟動電扇降溫。

* **物聯網遠端監控**：
  * 可連上 Wi-Fi 透過網頁即時瀏覽溫濕度數據。
  * 支援**遠端控制模式**：可手動強制開啟/關閉風扇，或一鍵恢復自動感應模式。
